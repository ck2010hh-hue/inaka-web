尚未连接
只要两端填相同的 API Key + 相同的口令，就会自动连到同一个存档（同一个 ID）。 两端都同步后，这里的 ID 应当完全一致——若不一致，说明没连到同一存档，点「重新连接存档」再同步即可。
1. 打开 jsonbin.io 免费注册登录，进入 Dashboard → API Keys 复制 Secret Key（X-Master-Key） 填上方「API Key」栏
2. 电脑、手机在「API Key」填同一个 Key，「同步口令」也填同一个
3. 点「保存设置」后，任意一端先点「同步」——代码会自动建好共享存档，另一端同步时自动找到它。
inaka-state.json
1. 打开 gitee.com 注册登录，新建一个私有仓库（如 inaka-workbench）
2. 进入 设置 → 私人令牌，生成 token 并勾选 projects 权限，复制填入上方
3. 「仓库名」可填完整路径 用户名/仓库名，也可只填仓库名，系统会用令牌自动补全用户名；电脑、手机填同一个，「同步口令」也填同一个
4. 数据 AES 加密后存入仓库，Gitee 只能看到密文；之后改动会自动双向同步。
